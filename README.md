# Flutter Lab Sheet 5

**Flutter Lists, Grids and Dynamic User Interface**

This repository contains 17 standalone Flutter programs for Lab Sheet 5.

## Run on Chrome

First time:

```bash
cd ~/Desktop
git clone https://github.com/NetraChauhan/flutter_lab_sheet_5.git
cd flutter_lab_sheet_5
flutter pub get
```

Run any question separately:

```bash
flutter run -d chrome -t lib/program_01.dart
```

Press `q` to stop the current program and change the file number up to `program_17.dart`.
